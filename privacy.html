医薬品供給ナビ プライバシーポリシー

最終更新日：2026年8月17日

「医薬品供給ナビ」（以下「本サービス」）は、医療用医薬品の供給状況を確認するためのWeb版およびiOSアプリを提供しています。本サービスにおける利用者情報の取扱いについて、以下のとおり定めます。

1. Web版で扱う情報

Web版の検索・供給状況確認は、ログインせずに利用できます。

  • 端末内に保存する情報：監視リスト（お気に入り）、前回確認日、確認済みの基準日、表示設定などをブラウザのlocalStorageへ保存します。これらは原則として利用中のブラウザ内だけに保存されます。
  • 採用品目CSV：「商品名」または「YJコード」列を含むCSVを利用者が選択した場合、ブラウザ内で公開医薬品データと照合します。CSV原本、ファイル名、CSV内容を運営者のサーバーやアクセス解析へ送信しません。照合後は一致した品目のYJコードを監視リストとして端末内に保存します。
  • バックアップと共有：監視リストのバックアップCSVは端末内で生成します。「共有」または「文章をコピー」を利用した場合に限り、利用者が選択した共有先またはクリップボードへ表示中の変更文面を渡します。
  • オフライン用キャッシュ：Service Workerを利用し、公開ページ、公開されている供給データ、アイコン等をブラウザのキャッシュへ保存する場合があります。監視リストや利用者が選択したCSV原本をService Workerのキャッシュへ保存しません。

2. Web版の利用状況の集計

Web版では、改善効果や障害を把握するため、プライバシーに配慮したアクセス解析サービス GoatCounter を利用します。Cookieや広告識別子を使ったサイト横断追跡は行いません。

集計するのは、ページの種類、参照元のドメイン、ブラウザ・OS等の技術情報、国単位の概略地域、および「検索結果あり」「検索結果なし」「監視リストの利用」「共有成功」「データ読込失敗」等の固定された機能イベントです。独自イベントに、医薬品名、検索語、YJコード、CSV内容、ファイル名、監視リストの内容、メールアドレスを含めません。品目別・ニュース・日別変更ページは個別名称ではなく共通のページ種別として集計します。

GoatCounterはセッション判定のためIPアドレスとUser-Agentを一時的に処理する場合があります。詳しくは GoatCounterのプライバシー説明 をご確認ください。ブラウザのDo Not Trackが有効な場合は、本サービス側の計測を停止します。

また、画面表示用フォントを取得するためGoogle Fontsへ接続する場合があります。この通信に伴い、接続元IPアドレス、要求日時、User-Agent等の一般的な通信メタデータをGoogle社が処理する場合があります。

3. iOSアプリで収集する情報

  • アカウント情報：掲示板へ投稿する場合、Appleでのサインインまたはメールアドレスとパスワードによる登録を利用します。Firebase Authenticationのユーザー識別子、表示名、メールアドレス（Appleで非公開を選択した場合は非公開リレーアドレス）を扱います。入力されたパスワードはFirebase Authenticationが認証のために処理し、運営者が平文で取得・保存することはありません。
  • 投稿情報：掲示板に投稿された本文、投稿日時、投稿者識別子。
  • 通報・不正利用防止情報：利用者が不適切な投稿を通報または投稿者をブロックした場合の対象投稿内容・識別子、通報者識別子。利用停止措置を行った場合は、対象者識別子と理由。
  • 認証・セキュリティ情報：Firebase Authenticationは、認証、アカウント管理、不正利用防止のため、メールアドレス等に加えてIPアドレスとUser-Agentを処理します。Firebase App CheckとApple App Attestは、正規アプリからの要求かを識別するための証明情報・トークンを処理します。
  • 診断情報：Firebase SDKは、サービス品質の把握に必要なFirebase user agent等の診断情報を、利用者に関連付けず処理する場合があります。
  • 端末内に保存する情報：お気に入り、最近閲覧した医薬品、表示設定、通知設定、非表示にした投稿者の識別子。これらは原則として端末内に保存されます。
  • お問い合わせ情報：利用者がメールで問い合わせた場合の送信元メールアドレス、本文および任意で添付したファイル。

医薬品の検索など、掲示板以外の主要機能はログイン不要で利用できます。検索語と最近閲覧した医薬品は端末内で処理し、検索のために外部送信しません。

4. 情報の利用目的

  • Web版の利用状況の集計、機能改善およびデータ読込障害の把握。
  • 掲示板機能の提供（投稿の表示・本人確認・管理）。
  • 不適切な投稿・迷惑行為への対応（通報内容の確認、投稿削除、利用停止）。
  • 利用者からのお問い合わせ対応。
  • 不正アクセスの防止、障害解析およびサービス品質の維持。

掲示板の投稿本文、表示名、職種表示および投稿日時は、掲示板を閲覧するすべての利用者に公開されます。メールアドレスは投稿画面に公開しません。投稿には患者名、連絡先などの個人情報や機密情報を記載しないでください。

5. 情報の保存

アカウント情報・投稿情報・通報情報・不正利用防止情報は、Google社の Firebase（Cloud Firestore / Authentication）に保存されます。通信にはHTTPSを使用し、保護対象の書き込みとアカウント操作は認証およびセキュリティルールで制限します。掲示板の投稿はログイン前も閲覧できる公開情報です。Firebase App Checkは正規アプリ由来の要求を計測しており、既存版の利用を妨げないことを確認した後に段階的に強制します。

Firebase Authenticationは不正利用防止のためIPアドレスのログを数週間保持します。その他の認証情報はアカウント削除まで保持され、削除後はGoogle社の稼働系およびバックアップシステムから180日以内に削除されます。医薬品データの更新ではGitHub社の配信基盤へHTTPSで接続するため、接続元IPアドレス、要求日時、User-Agent等の一般的な通信メタデータを同社が処理する場合があります。端末内の情報は、アプリの削除や端末設定の初期化により消去される場合があります。

6. 第三者提供

法令に基づく場合を除き、取得した情報を第三者へ販売しません。本サービスの提供・認証・保存・不正防止・データ配信・利用状況集計のため、Google Firebase、Apple、GitHubおよびGoatCounterが各サービスのプライバシーポリシーに従って必要な情報を処理します。広告配信や、他社アプリ・ウェブサイトを横断した追跡には使用しません。

  • Google プライバシーポリシー
  • Apple プライバシーポリシー
  • GitHub 一般プライバシー ステートメント
  • GoatCounter Privacy

7. アカウントおよびデータの削除

利用者は、アプリ内の「アカウントを削除」機能により、本人確認後に認証アカウントおよび公開中の本人投稿を削除できます。Appleでサインインした場合は、削除時にAppleとの連携も解除します。

通報記録は、重複通報の確認、調査および異議申立て対応のため作成日から90日後を有効期限とします。利用停止記録は、停止措置と異議申立て対応のため180日後を有効期限とします。運営者は毎月1回、期限到来済みの記録を確認して削除します。移行前に作成された期限情報のない記録も作成日時から期限を判定し、期限超過分を削除します。法令によりこれを超える保存が必要な場合は、その対象を必要最小限に限定します。削除に関するお問い合わせは下記連絡先でも受け付けます。
