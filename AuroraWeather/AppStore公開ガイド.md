# そらだま(空玉)App Store 公開ガイド

このプロジェクトは公開に向けて以下を**設定済み**です。残りはあなたのApple IDでしかできない作業なので、上から順に進めてください。

## ✅ 設定済み(このリポジトリに含まれるもの)

| 項目 | 内容 |
|---|---|
| バンドルID | `com.tkiyo1007.soradama`(+ `.widget` / `.watchkitapp`) |
| プライバシーマニフェスト | `PrivacyInfo.xcprivacy` を3ターゲットに同梱(位置情報: 機能目的・非紐付け・非トラッキング) |
| 暗号化の申告 | `ITSAppUsesNonExemptEncryption = NO`(HTTPSのみ=免除対象。アップロード毎の質問がスキップされます) |
| アプリアイコン | 1024px(iOS / watchOS 両方) |
| 位置情報の利用目的文 | 日本語で設定済み |
| プライバシーポリシー | リポジトリ直下 `soradama-privacy.html`(公開方法は手順4) |
| 対応デバイス | iPhone専用 + Apple Watch(iPad対応を外し、スクリーンショット準備を簡略化) |

## 手順1: Apple Developer Program に加入(未加入の場合)

- https://developer.apple.com/programs/ から加入(**年間 ¥14,800 程度**)。個人でOK
- 加入完了まで最大48時間ほどかかることがあります
- **無料アカウントのままではApp Storeに公開できません**

## 手順2: Xcodeでの最終確認

1. 3つのターゲットすべてで Team を選択(加入後は「kiyotaka takanishi (Individual)」のような有料チームを選ぶ)
2. (任意・推奨)App Group `group.com.tkiyo1007.soradama` を **AuroraWeather** と **AuroraWeatherWidgetExtension** の両方に追加 → ウィジェットが選択中の都市と同期します
3. 実機で一通り動作確認(位置情報許可 → 現在地表示 → 都市追加 → スワイプ → レーダー → ウィジェット → Watch)

## 手順3: App Store Connect でアプリを作成

1. https://appstoreconnect.apple.com/ → マイアプリ → 「+」→ 新規アプリ
2. 入力値:
   - プラットフォーム: **iOS**(watchOSは自動で含まれます)
   - 名前: **そらだま**(重複で弾かれたら「そらだま - 空玉」など)
   - プライマリ言語: **日本語**
   - バンドルID: **com.tkiyo1007.soradama**(初回はXcodeから一度アップロードすると選択肢に出ます)
   - SKU: `soradama001`(任意の管理用文字列)

## 手順4: プライバシーポリシーURLの用意

リポジトリの `soradama-privacy.html` をGitHub Pagesで公開するのが最速です:

1. このブランチを `main` にマージ(またはファイルをmainにコピー)
2. 公開URL: `https://tkiyo1007-eng.github.io/drugs-data/soradama-privacy.html`
3. ブラウザで開けることを確認し、App Store Connect の「アプリのプライバシー」に設定

## 手順5: アプリのプライバシー(質問票)の回答

App Store Connect → アプリのプライバシー:

- 「データを収集しますか?」→ **はい**
- 収集するデータ: **正確な位置情報** のみ
  - 利用目的: **アプリの機能**
  - ユーザーのIDに紐付け: **いいえ**
  - トラッキングに使用: **いいえ**

(同梱のPrivacyInfo.xcprivacyと同じ内容です。ズレると審査で警告が出ます)

## 手順6: スクリーンショット撮影

シミュレータで **⌘S** を押すと保存されます。必要なもの:

- **iPhone 6.9インチ**(iPhone 16 Pro Maxシミュレータ): 最低2枚、推奨4〜6枚
  - おすすめ構成: ①晴れの都市 ②雨の都市(パーティクルが映える)③10日間予報まで見える画面 ④雨雲レーダー ⑤ウィジェット(ホーム画面)
- **Apple Watch**: Watchシミュレータで2枚以上(Watch対応を出す場合)

## 手順7: アーカイブとアップロード

1. Xcode上部のデバイス選択を **「Any iOS Device (arm64)」** に
2. メニュー **Product → Archive**
3. Organizerが開いたら **Distribute App → App Store Connect → Upload**(すべて既定でOK)
4. 15〜30分ほどで App Store Connect の「ビルド」に反映されます

## 手順8: メタデータ入力 → 審査提出

下の文案をそのまま使えます。ビルドを選択し、スクリーンショットとメタデータを入れて「審査へ提出」。初回審査は通常1〜3日です。

## ⚠️ 公開前に知っておくべき注意点

1. **Open-Meteoのライセンス**: 無料APIは**非商用利用**が条件です。無料アプリ(広告・課金なし)での公開は一般に問題ありませんが、将来課金や広告を入れる場合は有料プラン(月€29〜)への加入が必要です。
2. **RainViewer**: 無料利用可ですが、アプリ内にクレジット表記が必要です(実装済み: 画面下部の「データ提供」表記)。
3. **審査での指摘がありがちな点**: 位置情報許可を拒否してもアプリが使えること(→東京フォールバック実装済み)、プライバシーポリシーURLが開けること。
4. **バンドルIDは公開後変更できません**。`com.tkiyo1007.soradama` 以外にしたい場合は提出前に変更してください。
