DATA PIPELINE

供給区分と補足情報の出典を、分けて表示します。

現在の供給区分は、厚生労働省「医療用医薬品供給状況」の公表値をもとに表示します。メーカー案内文・PMDAニュース・自動抽出やAI要約は、出典と情報の種類を明示して厚労省データと区別します。

厚労省が公表

各メーカーからの報告をもとに、厚生労働省が医療用医薬品の供給状況を平日ごとに公表します。

毎晩、自動取得

公表データを毎晩自動で取得・整形し、検証処理を通して公開します。自動処理でも取得漏れや変換誤りの可能性はあるため、データ日付と出典をあわせて表示します。

差分を検出

前日からの供給区分の変化に加え、厚労省公表値より新しいメーカー公式案内を照合します。メーカー・製品規格まで一致した差異だけを検索結果へ表示します。

翌朝、手元に

iOSアプリでは、お気に入りや採用品の変化を端末内で確認できます。表示されたデータ日付と出典もあわせてご確認ください。

GLOSSARY

供給ステータスの見方。

厚生労働省の報告内容を、医薬品供給ナビでは4つの状態に整理して表示しています。この見方を押さえておくと、検索結果がぐっと読み取りやすくなります。

通常出荷

厚労省の公表上、出荷量が通常の区分

厚労省資料で「A.出荷量通常」と報告されている区分です。地域・取引先ごとの在庫や受注可否を保証するものではなく、メーカーから販売中止予定などが別途公表されている場合もあります。

限定出荷

数量や販売先が制限された状態

需要の急増や増産対応などにより、メーカーが出荷数量・販売先を制限している状態です。入手しづらくなる場合があります。

供給停止

一時的に出荷できない状態

原薬調達や製造工程の問題などにより、一時的に出荷ができなくなっている状態です。再開時期は品目により異なります。

販売中止

製造・販売が終了した状態

メーカーが製造・販売を終了した状態です。今後の対応は、メーカー・卸の最新情報を確認し、医師・薬剤師等の専門職でご判断ください。

FAQ

よくあるご質問。

導入前によくいただくご質問をまとめました。解決しない場合はサポートまでお気軽にお問い合わせください。

データはどのくらいの頻度で更新されますか？

厚生労働省が公表する「医療用医薬品供給状況」データを毎晩自動で取得し、翌朝には最新の状態に更新されます（公表自体は厚労省による平日ごとの更新です）。

利用は無料ですか？

Web版・iOSアプリともに無料でご利用いただけます。会員登録も不要です。

対象になっている医薬品の範囲は？

厚生労働省が公表している医療用医薬品の供給状況データが対象です。一般用医薬品（OTC）や医療機器は対象に含まれません。

Web版とiOSアプリ版で機能に違いはありますか？

検索・供給ステータスの確認・監視リスト登録による定点観測（ブラウザ保存）・CSV保存はWeb版でもご利用いただけます。Web版の監視リストは再訪時に変化を確認する機能で、プッシュ通知と医療従事者向け掲示板はiOSアプリ限定です。

Android版のアプリはありますか？

現在ネイティブアプリは iOS 版のみですが、この Web 版はホーム画面に追加してアプリと同じように使えます（Chrome のメニューから「アプリをインストール」または「ホーム画面に追加」）。追加すると全画面で起動し、電波の届かない場所でも直前に取得したデータを表示できます。検索・監視リスト・CSV保存は Web 版でもすべてご利用いただけます。

表示されている情報は100%正確ですか？

厚生労働省の供給区分は意味を変えて上書きせず表示しています。見やすくするための差分集計や、メーカー資料の自動抽出・AI要約は出典情報と区別して表示します。ただし公表と実際の流通状況にタイムラグが生じる場合があるため、採用・処方・調剤上の判断は必ず医師・薬剤師等の専門職が最新情報を確認したうえで行ってください。

「通常出荷」なのにメーカーでは限定出荷・供給停止となっている品目があるのはなぜですか？

厚生労働省の公表値とメーカー公式案内では、更新時期や対象包装の範囲が異なることがあります。医薬品供給ナビは厚労省区分を上書きせず、メーカー公式案内の方が新しく、メーカー・製品規格まで一致した場合に「情報差異あり」と併記します。規格を特定できない案内は検索結果へ強い警告を出さず、詳細画面で原文確認を促します。実際の受注可否は卸・メーカーにもご確認ください。
