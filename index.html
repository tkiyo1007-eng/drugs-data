FEATURES

供給不安の時代の、新しいスタンダード。

医薬品供給ナビは、日々の確認作業が少しでも楽になるよう、機能を選び抜いて作りました。

毎日、自動で最新に

厚生労働省の公表データ（平日更新）を毎晩自動取得。朝いちばんに開けば、常にきのう時点の最新供給状況が揃っています。

変化を時系列で追える

「最近更新された品目」を時系列で表示。限定出荷への切り替わり、出荷再開──動きのあった薬から順にチェックできます。

お気に入りで毎日チェック

気になる医薬品を登録しておけば、状況の変化をまとめて確認。採用品目の監視リストとして毎日の業務に組み込めます。

全体像はドーナツ図で

市場全体のステータス構成比をサマリー表示。「いまどのくらい逼迫しているのか」を数字とビジュアルで俯瞰できます。

現場の声が集まる掲示板

「この代替薬で乗り切っている」──同じ悩みを持つ医療従事者どうしで情報交換できるコミュニティを内蔵しています。

スマホひとつで完結

調剤台でも、卸との電話中でも。スマホに最適化された UI で、PC を開かずにその場で確認が終わります。

DATA PIPELINE

データはすべて、厚生労働省の公表情報です。

表示するのは加工した憶測ではなく、厚生労働省「医療用医薬品供給状況」の公表データそのもの。取得から表示まで全自動のパイプラインで鮮度を保ちます。

厚労省が公表

各メーカーからの報告をもとに、厚生労働省が医療用医薬品の供給状況を平日ごとに公表します。

毎晩、自動取得

公表データを毎晩自動で取得・整形。人手を介さないため、取りこぼしや転記ミスがありません。

差分を検出

前日からステータスが変わった品目を検出し、「最近更新」として変化にフォーカスした形で整理します。

翌朝、手元に

アプリを開くだけで最新版に。忙しい始業前でも、供給状況の確認は数十秒で完了します。

GLOSSARY

供給ステータスの見方。

厚生労働省の報告内容を、医薬品供給ナビでは4つの状態に整理して表示しています。この見方を押さえておくと、検索結果がぐっと読み取りやすくなります。

通常出荷

制限なく入手できる状態

特に出荷の制限はなく、通常どおり注文・入荷ができる状態です。

限定出荷

数量や販売先が制限された状態

需要の急増や増産対応などにより、メーカーが出荷数量・販売先を制限している状態です。入手しづらくなる場合があります。

供給停止

一時的に出荷できない状態

原薬調達や製造工程の問題などにより、一時的に出荷ができなくなっている状態です。再開時期は品目により異なります。

販売中止

製造・販売が終了した状態

メーカーが製造・販売を終了した状態です。今後の出荷再開はないため、代替薬への切り替え検討が必要です。

FAQ

よくあるご質問。

導入前によくいただくご質問をまとめました。解決しない場合はサポートまでお気軽にお問い合わせください。

データはどのくらいの頻度で更新されますか？

厚生労働省が公表する「医療用医薬品供給状況」データを毎晩自動で取得し、翌朝には最新の状態に更新されます（公表自体は厚労省による平日ごとの更新です）。

利用は無料ですか？

Web版・iOSアプリともに無料でご利用いただけます。会員登録も不要です。

対象になっている医薬品の範囲は？

厚生労働省が公表している医療用医薬品の供給状況データが対象です。一般用医薬品（OTC）や医療機器は対象に含まれません。

Web版とiOSアプリ版で機能に違いはありますか？

検索・供給ステータスの確認・お気に入り登録による定点観測（ブラウザ保存）・CSV保存はWeb版でもご利用いただけます。お気に入りの変化のプッシュ通知と医療従事者向け掲示板はiOSアプリ限定の機能です。

表示されている情報は100%正確ですか？

厚生労働省の公表時点の情報をそのまま表示しており、独自の加工・推測は行っていません。ただし公表と実際の流通状況にタイムラグが生じる場合があるため、採用や代替薬の選定は必ず医師・薬剤師にご確認のうえご判断ください。

「通常出荷」なのに実際は製造中止になっている品目があるのはなぜですか？

本サービスが利用している厚生労働省「医療用医薬品供給状況」データは、限定出荷・供給停止といった一時的な出荷調整を追跡するための資料であり、製造中止（販売中止）の把握を主目的とした資料ではありません。そのため、メーカーが製造を終了していても、この資料上は最後に確認された「通常出荷」のまま長期間更新されずに残ってしまうことがあります。厚労省データに「薬価削除予定」の区分が含まれる品目については「薬価削除予定」バッジを表示していますが、それ以外の品目については各詳細に表示される「情報の鮮度（最終確認からの経過日数）」を目安に、経過が長い場合は卸・メーカーへの確認もあわせてご検討ください。
